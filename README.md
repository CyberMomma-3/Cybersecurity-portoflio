### 📋 HIPAA Security Risk Assessment
**Framework:** HIPAA Security Rule | NIST SP 800-30

A full security risk assessment for a fictional five-provider dental practice. Identifies 14 risks across administrative, physical, and technical safeguard domains using a Likelihood × Impact scoring matrix. Includes a complete asset inventory, threat and vulnerability analysis, controls assessment, and a phased remediation roadmap.

**Skills demonstrated:** Risk identification and scoring, HIPAA Security Rule (45 CFR §§ 164.302–318), NIST SP 800-30 methodology, controls gap analysis, remediation planning, Business Associate Agreement requirements

### 🚨 Incident Response Plan
**Framework:** HIPAA Security Rule | NIST SP 800-61

A complete Incident Response Plan covering all six phases — Preparation, Identification, Containment, Eradication, Recovery, and Lessons Learned. Includes a full ransomware attack scenario walkthrough, incident classification matrix, chain of command, and HIPAA breach notification requirements with deadlines.

**Skills demonstrated:** NIST SP 800-61 incident response lifecycle, ransomware response procedures, HIPAA Breach Notification Rule (§§ 164.400–414), chain of command documentation, tabletop exercise planning

📄 [View Incident Response Plan](./grc-projects/incident-response-plan.md)

### 🎓 Security Awareness Training Policy
**Framework:** HIPAA Security Rule §164.308(a)(5) | NIST SP 800-50

A formal Security Awareness Training Policy covering all workforce members in a dental practice setting. Defines training requirements for onboarding and annual refreshers, nine required training topics specific to healthcare environments, delivery methods, documentation standards, progressive disciplinary procedures, and a signed employee acknowledgment form.

**Skills demonstrated:** Policy development, HIPAA workforce training requirements, healthcare-specific threat awareness (phishing, vishing, physical security, clean desk, ransomware), documentation and recordkeeping standards, enforcement and compliance procedures
